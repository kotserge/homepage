In-context operator learning

In-context operator learning is the prediction of the behaviour of an operator the model has never seen, from a few examples of it. Given demonstrations of the new operator and a new input, one pretrained model returns the output without updating its weights.

G⋆=argGmin​ E​G(a∣C)−u(a)​2,C={(aj​,uj​)}j=1k​

G(a∣C) is the output of the model for the input a given the context C, a set of k input–output pairs from the same new operator, and u(a) the true output. Given are prompts of demonstrations per operator, from many families; at query time C and a. Missing are the operator and its coefficients, inferred from the demonstrations. Sought is u(a).
