In-context operator learning aims, similar as in foundational emulators, to generalize across many system's dynamics, allowing for predictions of the behavior of a new operator the model has not seen, from just a few demonstration of it. However, in contrast to foundational emulators, given these demonstrations of the new operator, such model predicts this without the need for re-calibration. More formally, one seeks

G⋆=argGmin​ E​G(a∣C)−u(a)​2,C={(aj​,uj​)}j=1k​,

where G(a∣C) is the output of the model for the input a given the context C, a set of k input–output pairs from the same operator, and u(a) the true output. At query time, only C and a are given and the operator as well as its coefficients have to be inferred from these demonstrations.
