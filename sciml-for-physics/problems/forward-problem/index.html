Forward problem

The forward problem is the computation of the solution of one fully specified system. Everything that defines the system is known, so the only unknown is the state itself. It is the problem every classical solver was built for, and the one a neural network can be trained on without any data.

N[u;λ]=f  in Ω×(0,T],B[u]=b  on ∂Ω,u(⋅,0)=u0​

u is the state on the domain Ω over (0,T], N the operator with coefficients λ, f the forcing, B the boundary operator with data b, and u0​ the initial state. All of them are given, the operator in explicit form; nothing is observed and nothing is missing. The state is sought for this one instance, not for a family.
