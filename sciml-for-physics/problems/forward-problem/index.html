The forward problem captures the space of computing the solution of one fully specified system. Under this setting, everything that defines the system is known (i.e., the operator and its coefficients, the external forces acting on the system), and the only unknown is the state itself. This is the problem every classical solver targets, and the one a neural network can be trained on without any data (e.g., the classical PINN setting).

N[u;λ]B[u]u(⋅,0)​=f=b=u0​​​in Ω×(0,T],on ∂Ω×(0,T],in Ω,​

u is the state on the domain Ω over (0,T], N the operator with coefficients λ, f the forcing, B the boundary operator with data b, and u0​ the initial state. An important distinction from a more general solution is that here we seek the state for this one instance.
