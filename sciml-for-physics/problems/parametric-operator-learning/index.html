In parametric operator learning, one approximates the solution operator of a differential equation by learning the map from the data that parametrize the problem (coefficient fields, source terms, initial/boundary conditions, …) to the corresponding solution. More formally, let A and U be function spaces of inputs and solutions, and μ a probability measure on pairs (a,u)∈A×U. One seeks

θ⋆=argθ∈Θmin​ E(a,u)∼μ​ ​Gθ​(a)−u​U2​,

where {Gθ​:A→U}θ∈Θ​ is a parametrized family of operators, typically a neural operator such as a DeepONet or a Fourier Neural Operator. The main benefit is that once Gθ⋆​ is found, the solution for a new input a is a single forward pass, orders of magnitude cheaper than solving the forward problem anew.

Nearby problems

Reduced-order modeling. Approximates the same parameter-to-solution map, but factors it through a low-dimensional latent state z, i.e., a↦z↦u=D(z), and evolves z in time with a reduced model, whereas operator learning maps the input directly to the solution.
