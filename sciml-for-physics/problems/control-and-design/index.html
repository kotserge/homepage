In control and design, one chooses the inputs of a known system (e.g., distributed control, boundary data, coefficients, or the domain shape) such that its response is as “good” as possible, meaning it minimizes a cost J that encodes the corresponding goal. This goal might represent an airfoil design with less drag or a field that keeps a plasma confined. Classically, this requires experts predicting a sufficient candidate and expensive trials (e.g., simulations or experiments). More formally, one seeks

c⋆=argc∈Cmin​ J(u,c)s.t.N[u;λ]=f(c),B[u]=b(c),u(⋅,0)=u0​,

where c is the input, J the objective, C the admissible set, and f(c) and b(c) the forcing and boundary data determined by the input. Since the state follows from the input, this is equivalent to minimizing the reduced objective J^(c)=J(u(c),c) over c alone, with c↦u(c) as the forward map. However, if this map is a surrogate instead of an exact solver, the optimization process might run into the surrogate-exploitation problem.

01

Nearby problems

Inverse Problem. While the Inverse Problem seeks a parameter λ which explains the state, there is no true c to recover, only one to fit J better. The question is therefore not identifiability, but constraints and robustness under uncertainty.

Policy Learning. The same task in closed loop, with N reduced to a black-box environment and the full state replaced by sensor readings; a reward replaces the adjoint.

02

Methods possible

Physics-Informed Neural Networks. The state uθ​ and the input c become jointly trainable, with the governing equations as a penalty or a hard constraint, similar in how one can jointly train uθ​ with the parameter λ for identifying the coefficient of the inverse problem.
