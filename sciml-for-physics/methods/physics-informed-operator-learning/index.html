where a=(λa​,fa​,ba​,u0,a​)∼μ is an input of the family, i.e., the varying coefficients, forcing, boundary data and initial state drawn from a measure μ over the set of instances, and βb​, β0​ weight the boundary and initial terms as in the PINN loss.
